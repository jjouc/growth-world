# 成长世界 · 草原寻宝记

为安卓平板设计的家庭本地版成长手册。使用原创方块地形、树木和绿宝石风格图形，没有外部字体、图片、追踪或第三方 API。

## 已实现

- 每天三个习惯，每个习惯一天最多一颗绿宝石；开始时间可调整。
- 困难三步卡：圈出来、说卡点、继续一小步。区分主动、提醒、等待帮助及没有卡住。
- 按日期补记过去的任务；误点可以确认后修正，不允许产生负余额。
- 首页是每月探宝地图，每天一个节点，点开查看当天三个任务。
- 今日位置明确标记；任务完成后点亮节点，未完成的过去节点不阻挡前进。
- 学习记录和奖励有独立入口。首页不再显示小发现或奖励预告。
- 学习记录：日期、范围、总数、错误数、具体卡点、后续情况；支持筛选、编辑和删除。学习结果不影响奖励。
- 自定义奖励、兑换确认、家长兑现记录；未兑现兑换可以取消并返还绿宝石。
- IndexedDB 本地自动保存，JSON 导出和导入（校验格式，确认替换）。
- PWA 安装、离线资源缓存；手机、平板和电脑响应式布局。

## 简化版使用

首页点击“今天的小任务”或地图上的今天节点，完成一个小动作就点“做到了”。困难任务先选择今天的实际情况。返回地图时，节点下方的三个小方块会显示当天进度。

地图支持切换到过去的月份、补记过去的日期。未来日期不可操作；不会因为漏记或没有完成前一天而锁住今天。每天最多三颗绿宝石。

旧版已经保存的学习记录、奖励、任务和文字都保留在本地数据及备份中；只是首页移除了文字填写和奖励预告入口。

## 电脑预览

在本项目目录启动：

    python3 -m http.server 8765 --bind 0.0.0.0

电脑打开 http://localhost:8765 。不要直接双击 HTML 文件作为长期入口。

如果从上级目录启动，网址应是 http://localhost:8765/growth-world/ 。

## 安卓平板试用与安装

1. 同一 Wi-Fi 的平板可以打开 http://电脑局域网IP:8765/ ，前提是电脑服务运行、防火墙允许且 Wi-Fi 允许设备互访。这用于预览界面和功能。
2. 局域网 HTTP 地址不支持可靠的 PWA 安装和 Service Worker 离线缓存。长期使用应将本文件夹中的资源上传到支持 HTTPS 的网页托管服务。
3. 平板通过支持 PWA 的浏览器打开正式 HTTPS 网址，首次联网加载完成，选择“安装应用”或“添加到主屏幕”。
4. 在“家长设置与备份”检查离线文件是否准备好。以后固定从同一个安装入口进入。
5. 网页托管只保存程序文件。学习记录不会上传服务器；没有跨设备自动同步。
6. 地址、端口、浏览器及安装入口改变，可能使用不同的本地存储。迁移时先导出备份，再从新入口导入。

## 保存与备份

每次操作只有在 IndexedDB 事务完成后才显示保存成功。建议每周导出备份到“文件”或网盘，并确认下载完成。清除网站数据、恢复出厂设置和设备丢失都可能导致记录丢失。申请浏览器持久保存不能代替备份。

导入备份会替换该入口的全部现有记录，不合并；导入前先导出当前记录。备份含孩子的记录，请自行妥善保存，不要一起上传到公开网页托管目录。

家长入口只是操作分区，没有密码锁。兑换需要确认，但孩子也可以进入家长设置。当前版本建议每台设备只打开一个应用页面进行编辑。

## 部署与更新

### GitHub Pages

将程序资源上传至新 repo 后，打开 Settings → Pages，选择 Deploy from a branch，分支 main，目录 / (root)。保存后等 GitHub Pages 部署完成，再使用设置页给出的 HTTPS 地址。

程序使用相对路径，支持项目网址的子目录部署。repo 中的 .nojekyll 文件让 GitHub Pages 直接提供静态资源。

公开 repo 只保存程序及使用说明；学习记录继续保存在设备本地。备份和预览截图已加入 .gitignore，上传时也要排除这些文件。

应用无需构建、npm 依赖或后台数据库。只发布 index.html、style.css、app.js、sw.js、manifest.webmanifest、icon.svg、两个 PNG 图标；不发布备份、验证脚本、README 或截图。

修改发布资源后，同时递增 sw.js 中的缓存名版本，确保已安装应用获取完整新资源。数据保存在独立的 IndexedDB 中，缓存升级不会删除学习记录。

不同电脑、手机和平板的数据各自保存。若未来加入云端同步，可以沿用记录结构，但还需要实现登录、数据库权限和同步冲突处理。
